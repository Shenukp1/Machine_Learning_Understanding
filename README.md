# Machine_Learning_Understanding
This project contains two parts that explore the notion of improving an model. Where `*-Partial` is the first attempt
and then the `*-Complete` is the model after described changes have been made. The concepts that are explored are hyperparameter,
overfitting, and underfitting.

## Usage

Make the script executable (once):

```bash
chmod +x run.sh
```

ML & Jupyter work:

```bash
./run.sh
```

GUI scripts (`grabimage.py`, `interactive.py`):

```bash
./run.sh gui
```
